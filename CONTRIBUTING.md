# How to Contribute

We welcome contributions to the lightweight-cpp-plugin-framework project! To ensure a smooth and effective collaboration, please follow these guidelines.

## Getting Started

1.  **Fork the repository:** Start by forking the project to your GitHub account.
2.  **Clone your fork:** Clone your forked repository to your local machine:
    \`\`\`bash
    git clone https://github.com/your-username/lightweight-cpp-plugin-framework.git
    cd lightweight-cpp-plugin-framework
    \`\`\`
3.  **Create a new branch:** For each new feature or bug fix, create a new branch. Use a descriptive name for your branch (e.g., \`feature/add-logging\`, \`bugfix/fix-crashes-on-startup\`).
    \`\`\`bash
    git checkout -b feature/your-feature-name
    \`\`\`

## Making Changes

*   **Code Style:** Adhere to the existing coding style of the project.
*   **Commit Messages:** Write clear and concise commit messages. A good commit message should explain *what* the change is and *why* it was made.
*   **Tests:** If you're adding new features, please write unit tests to cover them. If you're fixing a bug, add a test that reproduces the bug and then shows it's fixed.
*   **Documentation:** Update the documentation as necessary to reflect your changes.

## Submitting Your Contribution

1.  **Push your changes:** Push your local branch to your forked repository on GitHub:
    \`\`\`bash
    git push origin feature/your-feature-name
    \`\`\`
2.  **Create a Pull Request:** Go to the original lightweight-cpp-plugin-framework repository on GitHub and create a Pull Request from your forked branch.
    *   Provide a clear title and description for your Pull Request.
    *   Explain the changes you've made and why they are necessary.
    *   Reference any related issues.

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project, you agree to abide by its terms.

Thank you for contributing!
